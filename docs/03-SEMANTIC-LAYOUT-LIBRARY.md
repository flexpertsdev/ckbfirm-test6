## HERO SECTIONS

### #1 Split Hero with Depth
**Visual:** Content left (60%), striking image/visual right (40%), subtle parallax effect
**Content:** Headline, subheadline, 1-2 CTAs, optional trust badges, hero image
**Mobile:** Stack vertically - content first, image below
**Best for:** Professional services, B2B SaaS, local businesses, authority-building
**Avoid if:** Creative portfolio (too rigid), highly emotional brands (too structured)

### #2 Centered Authority Hero
**Visual:** Large centered typography, optional background image with overlay, minimal and confident
**Content:** Bold headline, short subheadline, single prominent CTA, optional trust indicators
**Mobile:** Same layout, just scales down
**Best for:** Premium services, consultants, agencies, statements of expertise
**Avoid if:** Need to show product visuals, complex explanations required

### #3 Full-Screen Cinematic Hero
**Visual:** Edge-to-edge video or animated gradient, content floats center, glass-morphism effect
**Content:** Large headline, brief tagline, single CTA, background video/animation
**Mobile:** Static image instead of video (performance), same centered content
**Best for:** Lifestyle brands, restaurants, hotels, creative agencies, high-impact launches
**Avoid if:** Professional/conservative brand, slow connections common, need multiple CTAs

### #4 Asymmetric Bento Hero
**Visual:** CSS Grid with varying box sizes, main content in largest box, supporting visuals in smaller boxes
**Content:** Primary message (large box), 3-4 supporting elements (images, stats, icons) in smaller boxes
**Mobile:** Boxes reflow into 2-column then 1-column grid
**Best for:** Modern tech companies, creative portfolios, SaaS products, design-forward brands
**Avoid if:** Traditional/conservative industry, simple message doesn't need visual complexity

### #5 Floating Card Hero
**Visual:** Elevated card floating above animated gradient background, soft shadows, modern feel
**Content:** Headline, description, form or CTA buttons, all within card
**Mobile:** Card remains but with less dramatic shadow, gradient still animates
**Best for:** Sign-up pages, app landing pages, lead generation, conversion-focused pages
**Avoid if:** Need large imagery, content too long for card format

### #6 Minimal Statement Hero
**Visual:** Lots of whitespace, large typography, single statement, maybe one subtle accent element
**Content:** One powerful sentence/question (6-10 words), optional small supporting text, single CTA
**Mobile:** Same concept, scales typography
**Best for:** Luxury brands, design studios, bold statements, confidence-driven messaging
**Avoid if:** Need to explain complex offering, multiple products/services to highlight

### #7 Split with Animated Product
**Visual:** Product demo/animation on one side, benefits/features on other, product animates on scroll
**Content:** Product visual (animated), feature list, headline, CTA
**Mobile:** Product animation at top, content below, smaller animation loop
**Best for:** SaaS products, apps, physical products with key features, tech demos
**Avoid if:** Service-based (no product to show), slow connections (animation heavy)

### #8 Parallax Layered Hero
**Visual:** Multiple depth layers moving at different speeds on scroll, creates 3D effect
**Content:** Headline, subheadline, CTA in foreground, decorative elements in background layers
**Mobile:** Reduced parallax or static (performance), same content
**Best for:** Creative agencies, modern brands, immersive experiences, storytelling sites
**Avoid if:** Accessibility concerns (motion sensitivity), professional/conservative brand

### #9 Dashboard Preview Hero
**Visual:** Animated dashboard/interface preview, shows product in action, slight tilt or perspective
**Content:** Dashboard screenshot/animation, headline about what it does, CTA to try/demo
**Mobile:** Simpler product visual, no tilt, stacked layout
**Best for:** SaaS products, analytics tools, dashboards, B2B software
**Avoid if:** Product isn't visual, service-based offering, complex UI would confuse

### #10 Video Background Hero
**Visual:** Looping background video (muted), dark overlay for text readability, content centered
**Content:** Headline, subheadline, CTA over video, play/pause control optional
**Mobile:** Static poster image instead of video, same content overlay
**Best for:** Lifestyle brands, restaurants, hotels, experiential products, emotion-driven
**Avoid if:** Limited bandwidth users, professional services (too flashy), accessibility concerns

## FEATURE / SERVICE SECTIONS

### #11 Horizontal Feature Cards
**Visual:** 3-4 cards in a row, equal size, icons/images at top, clean and scannable
**Content:** Icon or small image, feature title, 2-3 sentence description per card
**Mobile:** Stack vertically into single column
**Best for:** 3-4 key features/services, simple explanations, overview sections
**Avoid if:** More than 4 items (use grid), need detailed explanations (use alternating blocks)

### #12 Icon Grid with Hover
**Visual:** Symmetrical grid (2x3 or 3x3), cards lift on hover, icons animate
**Content:** Icon, title, short description (2-3 sentences), optional "Learn more" link per item
**Mobile:** 2-column grid, then 1-column on smallest screens
**Best for:** 6-9 services/features, equal importance, scannable overview
**Avoid if:** Features need detailed explanation, visual hierarchy needed (some more important)

### #13 Alternating Content Blocks
**Visual:** Zigzag pattern, image-text-image-text, alternating left-right, different accent colors possible
**Content:** 3-5 blocks, each with image, headline, description (50-100 words), optional link
**Mobile:** All blocks same layout - image top, text below
**Best for:** Detailed feature explanations, storytelling, step-by-step processes, 3-5 key differentiators
**Avoid if:** Need quick scanning (too much content), more than 5 items (gets repetitive)

### #14 Tabbed Feature Showcase
**Visual:** Horizontal tabs control large content area, active tab highlighted, smooth transitions
**Content:** 3-6 tab labels, large visual area with image/video and description per tab
**Mobile:** Tabs become accordion/dropdown, content stacks below
**Best for:** Multi-feature products, category organization, reducing page length
**Avoid if:** Less than 3 tabs (unnecessary), users need to see all at once

### #15 Feature Matrix (3x3)
**Visual:** Clean 3x3 grid, organized and comprehensive, consistent styling
**Content:** 9 features with icon, title, brief description each
**Mobile:** 2-column then 1-column stack
**Best for:** Comprehensive feature overview, 7-9 items, equal weight features
**Avoid if:** Features have different importance levels, fewer than 6 items (too much space)

### #16 Bento Feature Mix
**Visual:** Mixed-size boxes like iOS widgets, some large with images, some small with icons, modern feel
**Content:** 6-12 boxes varying size, mix of images, text, icons, stats
**Mobile:** Boxes reflow maintaining some size variation
**Best for:** Modern brands, visual interest, diverse content types, tech companies
**Avoid if:** Traditional brand, content needs equal hierarchy

### #17 Vertical Feature Timeline
**Visual:** Vertical line connecting features, alternating sides, progression feeling
**Content:** 4-6 features with icon, headline, description, connected by timeline
**Mobile:** Timeline moves to left edge, all content right-aligned
**Best for:** Sequential features, process steps, evolution/progression stories
**Avoid if:** Features aren't sequential, fewer than 3 items

### #18 Masonry Feature Wall
**Visual:** Pinterest-style grid, varying heights, organic arrangement, visual interest
**Content:** 8-12+ feature cards with images, text, varying content lengths
**Mobile:** 2-column masonry then single column
**Best for:** Diverse content, visual-heavy features, portfolio-style, 8+ items
**Avoid if:** Need strict organization, accessibility critical (unpredictable flow)

### #19 Carousel Feature Slider
**Visual:** Horizontal slider of feature cards, dots/arrows for navigation, cards slide in
**Content:** 5-8 feature cards with image, title, description, navigation controls
**Mobile:** Swipe-enabled, single card visible, dots below
**Best for:** Space-constrained layouts, mobile-first designs, visual features
**Avoid if:** SEO critical (hidden content), users need to see all features

### #20 Sticky Feature Scroll
**Visual:** Left side fixed with image/visual, right side scrolls through features, visual changes per feature
**Content:** 4-6 feature descriptions scrolling right, corresponding visuals left
**Mobile:** Normal scroll, image appears above each feature section
**Best for:** Detailed feature explanations, visual product demos, immersive experiences
**Avoid if:** Simple features, fewer than 4 items, accessibility concerns (complex scroll)

## CONTENT SECTIONS

### #21 Split Screen Scrollytelling
**Visual:** Screen divided vertically, one side sticky with visual, other side scrolls content
**Content:** 4-6 content chapters, corresponding visuals that change as you scroll
**Mobile:** Visuals appear above each content section, normal scroll
**Best for:** Story-driven content, process explanations, sequential narratives, educational content
**Avoid if:** Content not sequential, fewer than 4 sections, simple message

### #22 Bento Grid Layout
**Visual:** Modern grid with mixed-size blocks, feels like dashboard, iOS widget aesthetic
**Content:** 6-12 blocks varying size with text, images, stats, interactive elements
**Mobile:** Blocks reflow into 2-column then 1-column, maintaining some size variety
**Best for:** Modern about pages, feature highlights, diverse content types, tech brands
**Avoid if:** Traditional brand, content needs linear reading order

### #23 Accordion Content Sections
**Visual:** Vertically stacked expandable sections, clean borders, icons rotate on expand
**Content:** 5-10 collapsible items with title and expanded content (paragraphs, images, lists)
**Mobile:** Same pattern, works naturally with touch
**Best for:** FAQs, detailed features, reducing page length, optional content
**Avoid if:** All content critical to see, SEO important (collapsed content)

### #24 Tabbed Content Areas
**Visual:** Horizontal tabs with sliding indicator, content area below animates between tabs
**Content:** 3-6 tabs with labels, large content areas (text, images, media) per tab
**Mobile:** Tabs become accordion or dropdown selector
**Best for:** Categorized content, reducing scroll length, organized information
**Avoid if:** Less than 3 categories, users need to see all content simultaneously

### #25 Horizontal Scroll Section
**Visual:** Content scrolls horizontally instead of vertically, cards slide in from right
**Content:** 5-8 wide cards with images and text, snaps to each card
**Mobile:** Same horizontal scroll, smaller cards, swipe interaction
**Best for:** Timelines, journeys, sequential stories, breaking up vertical scroll
**Avoid if:** Accessibility concerns, users unfamiliar with horizontal scroll

### #26 Content with Floating Sidebar
**Visual:** Main content 2/3 width, sidebar 1/3 with related info, sidebar sticky
**Content:** Main content area, sidebar with TOC/related links/CTA/newsletter
**Mobile:** Sidebar moves below main content
**Best for:** Blog posts, long articles, documentation, educational content
**Avoid if:** Sidebar not needed, mobile-first audience (wasted space)

### #27 Full-Width Reading
**Visual:** Centered content column (max 65ch width), no sidebar, generous whitespace
**Content:** Article content with large hero, pull quotes, inline images
**Mobile:** Already optimized, just adjusts padding
**Best for:** Long-form articles, storytelling, reading-focused content, editorials
**Avoid if:** Need sidebar navigation, short content (feels empty)

### #28 Multi-Column Layout
**Visual:** Content flows into 2-3 columns like magazine, images span columns
**Content:** Text content, images, pull quotes arranged in columns
**Mobile:** Single column
**Best for:** Magazine-style content, visual editorial, modern publications
**Avoid if:** Accessibility critical (column reading can be tricky), long paragraphs

### #29 Progress Indicator Content
**Visual:** Long content with progress bar or chapter navigation, shows position
**Content:** Multiple sections/chapters, progress indicator (scroll %, chapters)
**Mobile:** Progress bar sticky at top, chapters in hamburger menu
**Best for:** Long guides, documentation, multi-chapter content, courses
**Avoid if:** Short content, single topic

### #30 Interactive Content Explorer
**Visual:** Click/hover to explore different content areas, reveals details on interaction
**Content:** Main visual/map/diagram, clickable hotspots revealing detail panels
**Mobile:** Tap to reveal, detail panels slide up from bottom
**Best for:** Complex explanations, interactive demos, explorable content, education
**Avoid if:** Critical SEO content (hidden), simple message, accessibility concerns

## GALLERY & PORTFOLIO SECTIONS

### #31 Masonry Gallery
**Visual:** Pinterest-style grid, varying heights, images arranged organically
**Content:** 12+ images with optional captions, lightbox on click
**Mobile:** 2-column masonry then single column
**Best for:** Photography portfolios, diverse image sizes, visual-heavy content
**Avoid if:** Need strict grid, few images (under 8), accessibility critical

### #32 Grid-to-Detail Transition
**Visual:** Uniform grid of thumbnails, click expands item to full-screen detail with animation
**Content:** Project thumbnails in grid, detailed view with full content
**Mobile:** Same interaction, full-screen detail optimized for mobile
**Best for:** Portfolio projects, case studies, product collections
**Avoid if:** Need simple lightbox, too many items (30+), SEO critical

### #33 Filterable Gallery
**Visual:** Filter buttons at top, grid rearranges smoothly when filtered, items fade in/out
**Content:** Filter categories, gallery items with category tags, grid of images/cards
**Mobile:** Filters become dropdown, grid 2-column then 1-column
**Best for:** Large portfolios, product catalogs, categorized content, 20+ items
**Avoid if:** Few items (under 12), single category

### #34 Carousel Gallery
**Visual:** Large centered image with prev/next arrows, thumbnails below, smooth transitions
**Content:** Gallery of images, navigation controls, optional captions
**Mobile:** Swipe between images, thumbnails below scrollable
**Best for:** Product photos, featured work, controlled viewing experience
**Avoid if:** Many images (tedious clicking), need to see all at once

### #35 Horizontal Scroll Gallery
**Visual:** Single row scrolling horizontally, momentum scroll, modern feel
**Content:** Images or cards in horizontal row, scroll or drag to navigate
**Mobile:** Swipe scroll, works naturally on touch
**Best for:** Image series, timeline galleries, modern aesthetic, 8-15 items
**Avoid if:** Older audience (unfamiliar), critical images (might miss)

### #36 Lightbox with Zoom
**Visual:** Click image opens full-screen overlay, can zoom in, prev/next navigation
**Content:** Gallery images, lightbox functionality, zoom on desktop
**Mobile:** Pinch to zoom, swipe between images
**Best for:** Photography portfolios, product detail, image-focused content
**Avoid if:** Simple needs (use basic gallery), many images (UI fatigue)

### #37 Split Gallery View
**Visual:** Two columns - grid of thumbnails left, large preview right updates on hover/click
**Content:** Thumbnail grid, large preview area, navigation between items
**Mobile:** Thumbnails top as horizontal scroll, preview below
**Best for:** Product galleries, organized portfolios, before/after comparisons
**Avoid if:** Need immersive experience, mobile-first audience

### #38 Story Gallery
**Visual:** Full-screen slides like Instagram stories, tap to advance, progress indicators
**Content:** Images/videos with captions, swipe/tap navigation, progress dots
**Mobile:** Native story-style navigation, works perfectly on mobile
**Best for:** Social-style content, behind-scenes, mobile-first audiences
**Avoid if:** Desktop-primary, need detailed captions, older audience

### #39 Comparison Slider
**Visual:** Before/after images with draggable slider to reveal, dramatic comparison
**Content:** Two images (before/after), slider handle, optional labels
**Mobile:** Touch drag or swipe slider
**Best for:** Transformations, product results, before/after showcases, dramatic change
**Avoid if:** Comparison not visual, more than one comparison (gets repetitive)

### #40 3D Tilt Gallery
**Visual:** Cards with 3D tilt effect following mouse, depth shadows, modern interaction
**Content:** Image/project cards in grid, mouse-reactive tilt effect
**Mobile:** No tilt (performance), normal grid with tap interaction
**Best for:** Modern portfolios, creative work, premium products, tech brands
**Avoid if:** Accessibility concerns, traditional brand, many items (overwhelming)

## DATA & STATS SECTIONS

**Visual:** Large numbers count up on scroll, modern typography, supporting labels
**Content:** 3-4 key statistics with numbers, labels, optional icons
**Mobile:** Stack vertically or 2x2 grid
**Best for:** Impact metrics, company stats, achievements, social proof numbers

**Content:** Data points, chart title, axis labels, legend
**Mobile:** Simplified chart, horizontal scroll if needed, touch tooltips
**Best for:** Data-heavy content, trends, comparisons, analytical audiences
**Avoid if:** Simple stats (overkill), data too complex for small screens

### #43 Progress Bars/Meters
**Visual:** Horizontal bars fill on scroll, percentage labels, skill/feature representation
**Content:** 5-8 items with labels and percentages, bars filling left to right
**Mobile:** Same layout, stacks vertically
**Best for:** Skills, feature completeness, survey results, comparison metrics
**Avoid if:** Arbitrary percentages, doesn't add value over text

### #44 Stats with Icons
**Visual:** Grid of stat blocks, icon above number, clean and organized
**Content:** Icon, number, label for each stat (4-6 stats)
**Mobile:** 2x2 grid then stack
**Best for:** Key metrics with categories, quick scanning, visual organization
**Avoid if:** Stats are primary message (use #41 instead), too many stats (over 8)

### #45 Timeline with Data Points

**Content:** Timeline with dates, stats/events at each point, connecting line

## MOBILE-FIRST REMINDERS

### Always Design Mobile First

Start with 375px width
Stack everything vertically
Single column layouts
Large touch targets (44px minimum)
Readable text (16px+ body)
Then enhance for tablet/desktop
### Common Mobile Adaptations

**Grids:**
- 4 columns → 2 columns → 1 column
- 3 columns → 2 columns → 1 column

**Split Sections:**
- Side-by-side → stacked (content first usually)

**Navigation:**
- Horizontal links → hamburger menu

**Forms:**
- Multi-column → single column
- Labels above fields always

**CTAs:**
- Side-by-side buttons → stacked full-width

**Videos/Images:**
- Reduce size or hide decorative elements
- Prioritize content over atmosphere

## ACCESSIBILITY CHECKLIST

### Every Pattern Must Have:

☐ Semantic HTML (header, nav, main, section, footer)
☐ Proper heading hierarchy (h1 → h2 → h3)
☐ Alt text on all images (descriptive, not "image")
☐ Color contrast 4.5:1 minimum (text)
☐ Color contrast 3:1 minimum (UI elements)
☐ Focus indicators on interactive elements
☐ Keyboard navigation works
☐ Form labels properly associated
☐ ARIA labels where needed
☐ No content hidden from screen readers (unless decorative)
☐ Motion can be reduced (prefers-reduced-motion)
☐ Touch targets 44x44px minimum
### Test With:

Keyboard only (Tab, Enter, Escape)
Screen reader (NVDA, JAWS, VoiceOver)
Lighthouse accessibility audit
WAVE browser extension
Color contrast checker
