## 🎨 Design System

### CSS Tokens

All styling is controlled via CSS custom properties in `src/styles/tokens/`:

#### **colors.css** - OKLCH Color System
- **Hue-based**: Change 2 hue values, get full color palette
- **Default hues**: `--hue-brand: 210` (blue), `--hue-accent: 30` (orange)
- **Step 13 customizes**: Primary/accent hues per project brand
- **Dark mode**: Fully supported, auto-adjusts semantic colors
- **Semantic tokens**: `--color-bg`, `--color-text`, `--color-primary`, etc.

#### **typography.css** - Fluid Type Scale
- **System fonts** by default (Georgia, system-ui)
- **Step 13 adds**: Google Fonts import + custom font families
- **Fluid sizing**: Uses `clamp()` for responsive typography (16-18px base)
- **Line heights, tracking, weights**: All configurable via tokens

#### **spacing.css** - 4px Grid System
- **Base unit**: 4px for consistent spacing
- **Fluid section spacing**: Responds to viewport size
- **Semantic scales**: `--spacing-xs` through `--spacing-7xl`

#### **animations.css** - Motion Tokens
- **Durations**: `--duration-fast`, `--duration-base`, `--duration-slow`
- **Easing curves**: Natural motion with proper curves
- **Respects `prefers-reduced-motion`**: Accessibility first
- **Shadows**: OKLCH-based shadows with dark mode support

## 🔧 Customization

### ⚠️ IMPORTANT: Do NOT Edit This Template Directly

This template is **read-only** for the pipeline. Project-specific customizations happen via **Step 13** (CustomizeTemplateStep):

1. **Color Hues**: Step 13 replaces `--hue-brand` and `--hue-accent` values
2. **Typography**: Step 13 adds Google Fonts import and updates font families
3. **Dark Mode**: Step 13 removes dark mode block if project uses light-only theme
4. **Site URL**: Step 13 updates `astro.config.mjs` and `robots.txt`

**How It Works:**
- Pipeline reads this **clean template**
- Applies simple string replacements
- Writes **complete customized files** to generated project
- Template remains generic for next project

## 🚀 Template Standards

### Must Be Generic

- ❌ No project-specific values (colors, fonts, content)
- ❌ No hardcoded domain names or URLs (use `SITE_URL_PLACEHOLDER`)
- ❌ No custom saturation/lightness overrides
- ✅ Use sensible defaults that work for 90% of projects
- ✅ Use placeholders that Step 13 replaces

### Must Be Valid

- ✅ All CSS must have balanced braces
- ✅ Dark mode block must be **uncommented** and **active**
- ✅ No malformed comments or syntax errors
- ✅ Package dependencies must be minimal and universal
- ✅ No `node_modules` directory checked in (use .gitignore)

### Must Be Maintainable

- ✅ Version tracking via `@template-version` comments
- ✅ Clear documentation for each system
- ✅ Follows Astro and Netlify best practices
- ✅ Can be updated without breaking Step 13 customization

{

### What's NOT Included (by design)

- ❌ **Tailwind CSS** - Uses CSS tokens instead
- ❌ **@fontsource packages** - Step 13 uses Google Fonts dynamically
- ❌ **Neon Database** - Not needed for static sites
- ❌ **Netlify Blobs** - Advanced feature, add per-project if needed
- ❌ **State management** (nanostores) - Add per-project if needed
- ❌ **Reading-time, date-fns** - Add per-project if needed

**Rationale**: Keep template lightweight. Projects add specific dependencies as needed.

### When Updating This Template

**Before making changes:**
1. ✅ Test with full pipeline on 2-3 different projects
2. ✅ Verify Step 13 customization still works
3. ✅ Check CSS validation (balanced braces)
4. ✅ Update `@template-version` in CSS files
5. ✅ Document breaking changes in this README

**Testing checklist:**
- [ ] Colors customized correctly (hues replaced)
- [ ] Typography customized (fonts imported)
- [ ] Dark mode works or is properly removed
- [ ] No orphaned braces or malformed CSS
- [ ] Build completes without errors
- [ ] Site displays correctly in browser

## 🐛 Troubleshooting

### Dark Mode Not Working
**Cause**: Dark mode block might be commented out
**Fix**: Ensure `@media (prefers-color-scheme: dark)` is **uncommented** in `colors.css`

### Colors Not Customizing
**Cause**: Step 13 might be reading wrong template or regex not matching
**Fix**: Verify `--hue-brand: 210;` exists in template (not custom value)

### CSS Syntax Errors
**Cause**: Unbalanced braces from malformed regex editing
**Fix**: Use template-based generation (Step 13 v2) instead of regex editing

### Fonts Not Loading
**Cause**: Google Fonts import missing or incorrect
**Fix**: Verify `@import url(...)` at top of `typography.css`

### Build Fails
**Cause**: Missing dependencies or incorrect import paths
**Fix**: Run `npm install` and check import statements use correct relative paths

## 💡 Design Philosophy

This template follows these principles:

1. **Zero CSS Knowledge Required**: Users never write CSS, only configure tokens
2. **Mobile-First**: Responsive by default, works on all devices
3. **Accessibility First**: WCAG AAA standards, keyboard navigation, screen readers
4. **Performance First**: Minimal dependencies, optimized assets, fast builds
5. **SEO Optimized**: Structured data, meta tags, sitemaps
6. **Dark Mode Native**: Not an afterthought, built into the system
7. **Maintainable**: Clear structure, documented, version tracked
